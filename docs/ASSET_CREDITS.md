# Asset Credits

Third-party assets used to build the chapter **Open Graph (social preview) images**
in `public/og/`. This file is generated from `assets/og-sources/sources.json` and
`assets/og-fonts/provenance.json`, which are the authoritative records.

All 30 illustrations come from **Wikimedia Commons**. They were chosen and reviewed by
the site owner, and verified before use:
- licence fields from the Commons API and the file page;
- complete upload history and uploader accounts;
- the licence of any source file they are based on;
- a byte-for-byte SHA-1 match against Commons;
- a scan for embedded or external content;
- a physics-accuracy check.

The review evidence is kept outside the repository.
No AI-generated imagery is used.

The unmodified files are in `assets/og-sources/originals/` (SHA-256 in `sources.json`).
The three edited copies are in `assets/og-sources/derived/`, written by
`scripts/derive-og-sources.mjs`.

**Common modification (all 30):** Scaled and placed, colours unchanged, on an ivory card inside the AjaySahuPhysics Open Graph frame (navy grid, gold rule, chapter title).

## Tooling (development only, not distributed)

- `@resvg/resvg-js` 2.6.2 (MPL-2.0) renders the SVGs to PNG in `scripts/generate-og-images.mjs`.

## Updating

1. Add or replace the source in `assets/og-sources/originals/` (unmodified, verified as above) and update `sources.json`.
2. Run `npm run og:generate` (re-derives the edited copies, then renders all 30 PNGs).
3. Regenerate this file and run `npm test` and `node scripts/verify-build.mjs` after a build.
